# 应用素材

植物装饰沿用已采纳原型：暖杏来自 `assets/plates/botanical.png`，青瓷与雾玫来自 `prototype/assets/botanical-*.png`。生成记录见原位置的 JSON／提示词与 `docs/design/visual-reference.md`。

品牌标题使用已有 Noto Serif SC Regular 字体子集；来源为 `prototype/assets/fonts/noto-serif-sc-0.woff2`，实际格式为 TrueType，复制为 `fonts/brand-serif.ttf`。字体仅用于已覆盖的品牌标题。正文与输入控件使用系统字体。OFL 许可证已随应用打包并注册至 Flutter LicenseRegistry，来源记录见原型字体目录。
