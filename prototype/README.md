# 可点击原型

用于阶段 2.3 试用：双方如何记分、购买、完成、退款，以及页面反馈是否清楚。全部使用内存中的演示数据，刷新页面恢复初始状态。

## 打开

直接打开 [way2we-demo.html](way2we-demo.html)。图片、字体和脚本已包含在单文件中，无需安装依赖。

也可以在项目根目录运行：

```sh
python3 -m http.server 56446 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:56446/prototype/`。修改源文件后，运行 `python3 prototype/package-demo.py` 更新单文件演示。

## 试用

- 默认阿禾 10 分、小满 0 分，已有一笔两份早餐、支付 20 分的待完成购买。首页右侧可以直接完成或取消。
- 点击“记一笔”，给阿禾加 10 分，再购买两份早餐，阿禾余额变成 0；切换到小满可以处理同一笔购买。
- 从“记录 → 购买记录”打开已完成购买，可以整笔取消退款。记分详情可以撤销，原记录与回退经过均保留。
- 从“小卖部 → 我的店铺”添加、编辑、上下架商品；从“约定”创建或修改约定。
- 点击顶部空间名称，进入成员与空间设置，尝试邀请小桥、全员同意、退出与重新加入。退出会自动处理涉及自己的待完成购买。
- 从“我的 → 应用设置 → 外观”选择暖杏、青瓷或雾玫；切换空间后保持个人主题。

电脑左侧提供演示身份、负余额、空白空间、长内容、字号和网络状态控制。手机宽度下点击右上角“演示设置”展开。“下一次提交失败”只生效一次，失败后直接重试，已填内容保留。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css`、`app.js` | 手机界面、演示设置和交互 |
| `model.js` | 空间、积分、约定、购买与成员的内存状态 |
| `assets/`、`../assets/plates/` | 独立生成的图片与本地字体 |
| `package-demo.py` | 打包可直接打开的 HTML |
| `way2we-demo.html` | 当前单文件演示 |

验证范围和实现阶段事项见[原型验证记录](../docs/design/prototype-validation.md)。原型用于确认流程与界面，正式客户端和服务端按 Flutter + Go 方案实现。
