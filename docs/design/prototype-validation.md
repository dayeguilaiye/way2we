# 可点击原型验证记录

日期：2026-09-22。版本：阶段 2.3 首轮浏览器原型。

入口：[使用说明](../../prototype/README.md)、[单文件演示](../../prototype/way2we-demo.html)。所有演示操作作用于当前页面内存；刷新或重置后回到初始状态。

## 页面覆盖

| 区域 | 可操作内容 |
| --- | --- |
| 近况 | 个人余额、成员入口、快捷记分、本人待处理购买、空间近况 |
| 约定 | 生效／停用与成员筛选、新增与编辑、详情、停用／启用、修改记录、记分 |
| 小卖部 | 逛店与经营、商品详情、新增／编辑、可选图片、上下架、数量与支付确认 |
| 购买 | 待完成／已完成／已取消、双方身份、支付快照、经过、整笔完成和退款 |
| 记录与通知 | 成员积分明细、购买状态筛选、记分撤销、来源详情、当前空间通知与已读 |
| 空间 | 创建与切换、成员余额与昵称、邀请接受与全员同意、退出与恢复 |
| 个人 | 账号入口、应用设置、三套外观、演示身份切换 |

## 已执行的操作检查

操作检查使用 Chrome 中的实际控件；纯状态检查补充验证历史分值与重复操作。以下结果属于原型范围。

| 路径或边界 | 实际结果 |
| --- | --- |
| 阿禾初始 10 分，按 +10 约定记分 | 阿禾 20 分，小满 0 分，生成新的记录 |
| 阿禾再购买 2 份、每份 10 分的早餐 | 阿禾 0 分，小满 0 分，新增一笔支付 20 分的待完成购买 |
| 小满确认该笔完成，随后取消 | 先记录完成，再整笔退回 20 分，完成与退款经过保留 |
| 新建约定遇到一次模拟失败，再次提交 | 名称与已填字段保留，重试后成功保存 |
| 阿禾邀请小桥，小桥接受，小满随后同意 | 接受后仍等待；全部当前成员同意后加入，初始余额 0 |
| 初始场景中小满退出 | 原待完成购买自动取消，阿禾 10 → 30 分，小满成员状态为已退出 |
| 小满重新加入 | 直接恢复参与，已取消购买保留取消结果 |
| 小满选择雾玫，再进入另一个空间 | 页面继续使用雾玫，空间余额分别管理 |
| 对同一购买重复退款 | 只发生一次退款 |
| 原 +10 记分的约定已改为 +20，随后撤销旧记录 | 按原值回退 10 分，重复撤销保持一次回退 |
| 扣分使余额为负，随后尝试购买 | 负余额保留，购买被余额校验阻止 |
| 买方退出后，仍在空间的卖方取消已完成购买 | 退款进入退出成员保留的余额 |
| 全部成员退出后恢复参与 | 空间、余额与历史仍可恢复 |

数量输入在输入时更新合计，提交时使用当前数量。提交期间控件禁用；原型为每次记分和购买保留请求标识，并对已经完成的退款和撤销保持一次结果。

## 界面与资源检查

- 检查 1440 × 1080 的电脑预览、390 × 846 的手机视口，以及 320 × 780、长昵称和商品名、160% 阅读字号。退款说明、对象和操作按钮可以换行，弹层按内容滚动。
- 退款确认沿用小标题、商品摘要、退款对象与正文尺度金额；首页两条近况在标准手机视口内完整展示。
- 三套主题使用角色色表，同步应用到表面、文字、边界、操作和植物装饰，选中主题显示勾选。
- 青瓷首页的说明放在植物左侧留白中，390 像素、320 像素及 160% 字号下均可完整阅读。
- 图片、字体和脚本均可本地加载；单文件通过 `file://` 打开时，未发现损坏图片或外部脚本、样式依赖。
- 当前图片来源和生成提示词均保留。素材来源扫描检查 12 张图片，缺失来源数量为 0。
- 精确首页尺寸的图像比较整体分数为 0.8641。主色采用[主题规范](themes.md)中的文字对比合格色值，头像使用独立生成的演示照片，记录头像与实际操作者一致。

视觉工具的局部差异检测仍标记头像、图标和部分主题色区域；两张头像的素材细节密度关卡未通过，原图与成品已人工查看。构建状态文件保留这一结果，完整视觉关卡未标记通过。截图和比较结果保存在 `.impeccable/review/`，供后续对照。

独立评审最终 disposition 为 `ship`：复核确认“保留关卡限制披露”和“青瓷文案可读性修正”两项动作均已完成。该结论覆盖这两项修正，完整视觉关卡仍保持上述限制。评审记录见 [prototype-finish-review.md](../../.impeccable/review/prototype-finish-review.md)。

## 实现阶段验证

实际账号认证、服务端权限、事务持久化、并发购买、请求提交成功后超时重试、进程重启恢复及通知事件可靠投递，在阶段三按[业务验收场景](../product/acceptance-scenarios.md)验证。当前网络失败发生在内存变更之前。

Flutter 双端实现时验证原生返回、键盘、安全区域、系统字号和真实设备触控。当前原型的演示字号和浏览器布局提供结构参考。

原型已获用户采纳。下一步形成阶段三的工程方案与第一条 Flutter + Go 实现任务；本记录保留原型检查范围和正式实现需要验证的事项。
