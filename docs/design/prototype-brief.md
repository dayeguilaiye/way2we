# 可点击原型

状态：阶段 2.3 原型已获用户采纳，作为正式实现的交互与视觉基准。首页、核心页面、操作界面与修订后的退款确认作为视觉依据。入口见[使用说明](../../prototype/README.md)，执行范围见[验证记录](prototype-validation.md)。

设计模式：Operate。原型需要让用户实际完成创建约定、记分、经营店铺、购买、完成与退款，并能从记录解释余额变化。

## Direction contract

THESIS：暖白纸感承载共同生活记录，清楚展示当前空间、余额和可处理交易。

OWN-WORLD：沿用暖杏、青瓷、雾玫完整主题，首页保留植物光影与文案，业务页面保持清楚的正文和柔和控件；短确认弹层使用小标题与正文信息行。

STORY：选择空间，查看近况，按约定记分，在对方店铺购买，双方处理交易并查看记录。原型外部提供演示身份、场景和网络状态控制。

FIRST VIEWPORT：首页依次展示我的／空间／通知、顶部文案与右侧装饰、成员余额、记一笔、待处理、空间近况，以及四个底部入口。以已选首页图的比例和间距为依据，手机视口优先。

FORM：延续用户已确认的页面构图，原型使用真实文字与控件、独立图片及内存演示状态。页面与弹层的返回路径沿用交互稿。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验证范围

- 双方共用同一份演示数据，积分与小卖部按空间隔离，默认示例为阿禾 10 分、小满 0 分和一笔早餐待完成购买。
- 约定新增、编辑、停用与重复记分，原分值撤销，以及完整历史。
- 商品新增、编辑、上下架、可选图片，购买正整数数量和余额核验。
- 购买按整笔完成和取消退款，退出自动取消待完成购买，历史与余额保留，老成员可恢复。
- 记录、站内通知、成员、邀请接受与全员同意、空间选择、个人外观。
- 长内容、大字体、窄屏、空状态、余额不足、提交中、网络不可用与失败重试。

## 使用方式

原型放在项目的 `prototype/`，演示设置位于应用界面之外。演示状态保存在内存，刷新或重置回到初始数据。手机尺寸下隐藏桌面辅助栏，通过“演示设置”展开控制。正式手机应用继续使用 Flutter，服务端按既有 Go 方案推进。
