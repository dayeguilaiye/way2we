# 视觉设计任务说明

状态：阶段 2.2 已确认视觉方向与四张[关键页面设计图](core-pages.md)，完整主题色表、五个[操作界面与两个多主题示例](action-pages.md)已完成，新增视觉稿待评审。视觉依据为用户选中的[暖杏枝叶首页](../../.impeccable/mocks/themes/apricot-reference.png)，保留暖白纸感、杏陶色、书卷感标题、顶部文案及右侧植物光影。交互依据为已确认的[页面结构与交互草图](app-structure.md)，产品背景见 [PRODUCT.md](../../PRODUCT.md)。

设计模式：Operate，帮助成员理解当前空间并完成日常操作。

## 设计目标

为情侣及家庭成员提供适合日常使用的手机界面，让成员容易辨认当前空间、自己的积分、可以操作的交易和最近发生的事情。页面以任务清楚、阅读轻松、操作方便为先，iOS 与 Android 使用统一品牌风格。

## 首批设计页面

| 页面 | 需要在视觉上说明的重点 |
| --- | --- |
| 首页／近况 | 顶部头像与我的、空间切换、通知；主题文案与右侧装饰；余额与记分入口；右侧带完成和取消按钮的待处理交易；空间近况及四个底部入口 |
| 约定与记分 | 约定名称、适用成员、加减分值及记一笔；记分表单清楚展示对象、实际分值与余额变化 |
| 小卖部 | 逛小卖部与我的店铺之间的切换、店主身份、商品与服务的名称和积分单价，以及经营时的编辑和上下架操作 |
| 购买详情 | 双方身份、单价、数量、实际支付积分、整笔状态、完成与取消操作，以及可追溯的历史 |

以选定首页为基础，将同一套设计语言应用到其他关键页面，并补充记分、购买确认和退款确认等短任务界面。青瓷与雾玫的首页配色示例沿用同一构图，用于验证主题的整体协调性。

## 示例内容与固定结构

示例使用虚构空间“一起的小日子”和成员“阿禾”“小满”，沿用交互稿中连续且一致的积分变化。首页示例中阿禾余额为 10 分，存在一笔向小满购买两份早餐、已支付 20 分的待完成交易。

首页顶部顺序为头像／我的、空间名称、通知；底部顺序为近况、约定、小卖部、记录。待处理交易直接显示右侧完成与取消按钮，余额变化和状态均配有明确文字。

顶部文案区保留“平凡的日常，也是值得好好记录的生活。”以及“一起，让日子更温柔一点。”，右侧安排植物装饰。文案、图片与业务区域分别布局，兼顾长内容、窄屏和大字体。

正式产品名称仍待确定，设计图使用上述演示空间名称承载主要内容。

## 设计约束与交付

- 已确认的导航、信息层级和操作方式是视觉设计的基础，页面采用平等的成员称呼。
- 文字与控件适合手机阅读和触控；长昵称、较长商品名称、负余额及多份购买具有清楚的排布方式。
- iOS 与 Android 保留系统返回、键盘、安全区域及文字缩放的适配要求。
- 按所选视觉方向生成关键页面设计图，整理完整配色、文字层级、间距、控件与状态规范，供可点击原型和 Flutter 实现使用。
- 主题由完整颜色角色表与首页装饰图构成，每个人自行选择，在全部空间沿用；各主题共用布局、文字层级、图标与交互。
- 图片设计稿用于评审外观；点击行为在原型验证，实际数据和系统行为在双端实现验证。
