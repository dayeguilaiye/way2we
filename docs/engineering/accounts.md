# T01 邮箱登录与个人外观

## 交付范围

Flutter 登录页、“我的”、账号昵称与外观选择使用真实 Go API 和 PostgreSQL。邮箱验证码同时完成注册与登录；同一规范化邮箱恢复原内部账号、昵称与主题。登录后的当前入口为“我的”，空间业务从 T02 接入。

用户已确认本阶段完成本地完整流程。邮件经 SMTP 投递至本机 Mailpit 收件箱，真实供应商与已验证发件域名在正式邮件接入时确定。

## 服务端

`internal/account` 对外提供申请验证码、登录、会话验证／撤销、读取和修改个人资料。`internal/httpapi/account.go` 负责解析、认证和共享错误协议；入口 `cmd/api` 装配服务及投递 worker。迁移 `00002_accounts.sql` 建立邮箱身份、会话、验证码和频控表。

邮箱仅接受 ASCII，去除首尾空格并统一小写，保留点和 `+` 标签。密码学随机生成六位验证码；同邮箱操作使用事务锁串行执行。验证码消费、内部账号取得／创建和会话签发原子提交。会话为 32 字节随机凭据、有效期 30 天，数据库仅保存 SHA-256 摘要；退出仅撤销当前会话。

验证码有效 10 分钟，每份最多错误尝试 5 次，重发间隔 60 秒，重发立即使旧码失效。固定窗口默认预算：每邮箱每小时 5 封、每来源每小时 20 封；每来源每 10 分钟验证 60 次。三个总量预算通过 `.env.example` 的 `AUTH_*` 配置。来源使用 TCP 对端地址；正式反向代理接入时配置可信代理及来源解析。

申请受理时，HMAC 摘要和 AES-GCM 加密的投递材料与任务一同落库。后台每秒领取任务，30 秒租约，外部发送超时 8 秒；失败后间隔 10 秒重试，总共最多 5 次。任务重试使用同一验证码与 Message-ID；进程重启后可接管过期租约。投递成功、验证码消费、作废或到期后清除相应秘密材料。到期元数据保留一天；过期会话与到期频控桶定期清理。邮件发送确认丢失时可能重复送达，同一验证码仍只可消费一次。

昵称／主题修改使用账号范围的 UUID 操作标识，与既有 `commands` 表共享去重语义；每次重放重新核验有效会话。同标识同参数返回已保存的结果，不同参数返回 409。客户端在重放后读取当前资料，避免历史快照覆盖较新的显示值。

日志记录路由模板、请求编号、经过验证的账号 ID、稳定错误分类；投递失败记录任务 ID、来源请求编号、尝试次数与耗时。邮箱、验证码、凭据、请求正文和原始供应商错误不进入日志。

## Flutter

`features/account/data` 负责 DTO、API 与待确认资料操作存储；`application` 负责登录及账号状态；`presentation` 实现登录、昵称、外观和退出流程。Dio、路由、主题和会话协调沿用共用层。

凭据先写入平台安全存储，再发布已登录状态。启动恢复凭据后重新读取服务端资料；会话过期转入登录。所有账号异步响应按会话代次核验，旧响应不会写入新账号状态。

修改昵称／主题前，把操作标识及参数保存到当前账号的安全存储。响应丢失或应用重启后保留“核对保存结果”入口，以原标识重试并读取当前资料；核对完成前阻止发起下一次资料修改。退出后这些最小核对信息仍归原账号所有，下次同账号登录时恢复。

主题使用个人账号设置，在所有空间共用。暖杏、青瓷、雾玫沿用 `DESIGN.md` 的 token 与原型植物素材；切换成功后更新全局外观。普通表单保持系统字体，品牌标题使用已采纳字体子集。素材与许可证见 `apps/mobile/assets/README.md`。系统深色设置下保持已确认的浅色品牌主题。

## 本地运行与依赖

`make dev` 启动 PostgreSQL 与 Mailpit，创建本机认证密钥，迁移数据库并启动 API。打开 [本地收件箱](http://127.0.0.1:8025)，输入任意符合格式的测试邮箱即可接收验证码。Mailpit 的 SMTP 和管理端口仅映射至本机回环地址，当前配置用于模拟器开发。

`make setup-local` 创建 `.secrets/auth.key`（32 字节随机密钥的十六进制文本，文件权限 0600），已存在时保留。`.secrets/` 与 `.env.local` 均忽略提交。保留密钥以恢复尚未完成的本地验证码投递；新环境独立生成。当前发送适配器只允许回环 SMTP，正式环境启动需要先接入生产发送适配器。

新增开发依赖 **Mailpit v1.31.3，MIT**，`compose.yaml` 固定镜像及 SHA-256 摘要。使用 Go 标准库 `net/smtp` 接入本地收件箱；正式邮件发送通过 `account.Sender` 适配。无新增 Go／Flutter 第三方包。

依据：[Mailpit Docker 文档](https://mailpit.axllent.org/docs/install/docker/)、[Mailpit v1.31.3](https://github.com/axllent/mailpit/releases/tag/v1.31.3)、[Go net/smtp](https://pkg.go.dev/net/smtp)。

## 验证入口

- `make check`：格式、静态分析、Go／Flutter 单元及组件检查、OpenAPI 静态检查。
- `make test-integration`：隔离 PostgreSQL schema；验证码并发消费、错误上限、过期、重发、投递重试／租约恢复、账号恢复、资料幂等、撤销会话与日志脱敏。
- `make check-auth-runtime`：真实本地 SMTP、HTTP 及 15 组共享契约响应，包括 204 空正文、重复标识、字段错误与退出后的 401。
- `make test-account-device DEVICE=<设备 ID>`：真实 API 与 Mailpit，双端登录、更正错误验证码、修改昵称／三套主题、恢复本机会话、退出后重新验证同邮箱。测试键盘输入由 Flutter 测试通道驱动；OS 原生截图存入 `.impeccable/review/t01/`，日志存入 `.artifacts/t01/`。

正式邮件送达、国内／海外网络、真实手机、最低系统版本及发布签名在上线准备中验证。
